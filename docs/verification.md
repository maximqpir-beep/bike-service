# Проверка проекта

Дата: 30 сентября 2026 года.

- Исходники приложения и тестов скомпилированы для Java 17 компилятором Eclipse ECJ.
- Локально выполнены 18 JUnit-тестов с настоящими JDBC-репозиториями на H2 в режиме PostgreSQL: 18 успешных, 0 ошибок.
- Проверены CRUD, бизнес-правила, сохранение даты завершения, начальные данные, статистика, текст с SQL-символами, содержимое Excel и ошибки ввода/подключения.
- Локальная проверка H2 не доказывает совместимость с PostgreSQL. Для этого предусмотрен GitHub Actions: стандартная Maven-сборка на JDK 17, те же тесты на PostgreSQL 16 и запуск упакованного JAR с экспортом из PostgreSQL.
- Результат CI смотрите во вкладке Actions. Пока запуск не завершился успешно, проверку PostgreSQL нельзя считать пройденной.

Локальная среда содержит JRE без javac, поэтому для локальной компиляции использован ECJ. В репозитории стандартный pom.xml для JDK 17; временные настройки проверки не включены.
