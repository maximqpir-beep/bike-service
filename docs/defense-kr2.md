# Защита КР №2: короткие ответы

## Рассказ о проекте

> Это JavaFX-приложение велосервиса. Интерфейс описан в FXML и оформлен CSS. Controller принимает действия пользователя, Service проверяет бизнес-правила, DAO выполняет параметризованные SQL-запросы через JDBC, а PostgreSQL хранит данные КР №1. Таблица обновляется через ObservableList и показывает заявки вместе с именем клиента.

## Частые вопросы

**Что такое Stage, Scene и Node?**  
`Stage` — окно. `Scene` — содержимое окна. `Node` — любой элемент внутри Scene: кнопка, таблица, поле или контейнер.

**Зачем FXML?**  
FXML хранит структуру интерфейса отдельно от Java-кода. `main-view.fxml` описывает главное окно, `request-dialog.fxml` — форму заявки.

**Как FXML связан с Controller?**  
`fx:controller` указывает класс контроллера. `fx:id` связывает элемент с полем `@FXML`. `onAction="#addRequest"` вызывает метод контроллера.

**Зачем ObservableList?**  
`TableView` наблюдает за списком. После `source.setAll(...)` таблица автоматически показывает новые данные.

**Как работают поиск и фильтры?**  
`FilteredList` хранит предикат. Он проверяет поисковую строку, статус и тип велосипеда. `SortedList` связывается с comparator таблицы.

**Где CRUD?**  
Кнопки вызывают Controller, Controller — `ServiceRequestService`, а сервис — `ServiceRequestDao`. SQL находится только в `JdbcServiceRequestDao`.

**Что такое JDBC?**  
Стандартный Java API для базы данных: `Connection` открывает соединение, `PreparedStatement` выполняет SQL с параметрами, `ResultSet` содержит строки результата.

**Зачем PreparedStatement?**  
Пользовательские значения передаются отдельно через `?`, `setString`, `setLong`, `setBigDecimal`. Это сохраняет типы и предотвращает SQL-инъекцию через значения.

**Что делает AbstractJdbcDao?**  
Это абстрактный родитель JDBC-DAO. Он хранит общий `ConnectionProvider` и общий метод обработки `SQLException`. Конкретные DAO наследуются и содержат SQL своих таблиц.

**Где бизнес-логика?**  
В `ServiceRequestService`: обязательные поля, существующий клиент, диапазон стоимости, начальный статус, допустимые переходы и запрет изменения завершённых заявок.

**Как связаны сущности?**  
Один клиент имеет много заявок. `service_requests.client_id` — внешний ключ на `clients.id`. В форме пользователь выбирает клиента по имени и телефону из `ComboBox`.

**Как обрабатываются ошибки?**  
DAO превращает `SQLException` в `DatabaseException`, сервис бросает `BusinessException`, Controller показывает сообщение через JavaFX `Alert`. Приложение продолжает работать.

**Как работает экспорт?**  
`FileChooser` получает путь от пользователя. `ExcelExporter` через Apache POI записывает текущий отфильтрованный и отсортированный список в `.xlsx`.

**Зачем Docker?**  
Docker Compose одинаково поднимает PostgreSQL у всех участников команды, публикует порт и сохраняет данные в volume. JavaFX работает на компьютере отдельно и подключается к опубликованному порту через JDBC.
