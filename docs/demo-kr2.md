# Демонстрация КР №2 за 5–7 минут

1. Покажите `docker compose ps`: PostgreSQL имеет состояние `healthy`.
2. Запустите `javafx-client/run.ps1` и покажите главное окно без консольного ввода.
3. В таблице покажите клиента, велосипед, статус, стоимость и дату.
4. Найдите `Trek`, включите фильтр статуса и типа, измените сортировку.
5. Добавьте заявку: клиент выбирается из `ComboBox`, статус автоматически `Создана`.
6. Отредактируйте заявку и последовательно переведите `Создана → Принята → В работе → Завершена`.
7. Продемонстрируйте ошибку: пустая марка, отрицательная цена или запрещённый переход.
8. Удалите тестовую заявку: сначала появляется подтверждение.
9. Откройте вкладку «Статистика» и назовите восемь показателей.
10. Отфильтруйте таблицу, нажмите «Экспорт .xlsx», выберите путь и откройте файл.

Код для показа: `main-view.fxml`, `MainController`, `ServiceRequestService`, `JdbcServiceRequestDao`, `database.properties`, `application.css`.
